## Project Overview
This project analyzes an marketing campaign using Microsoft Excel. The goal is to evaluate campaign performance and provide actionable insights using pivot charts.

## Objectives
1. Analyze key marketing metrics
2. Measure campaign effectiveness
3. Identify niches with greatest return and performance trends
4. Present insights using Excel charts and summaries

## Tools used
* Microsoft Excel Pivot Tables
* Charts and graphs
* Basic Excel formulas

## Key Metrics Analyzed
* Conversion rate
* Customer Rate
* Campaign reach and performance

## Insights and findings
* Identified top-performing campaigns
* highlighted trends in customer engagement
* Highlighted top-performing niches
